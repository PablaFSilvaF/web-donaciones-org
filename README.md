# Web Donaciones – Solidarios en Acción

Sitio para visualizar proyectos, buscar/filtrar eventos, aceptar donaciones en línea y mostrar notificaciones de logros y campañas.

## Módulos
- Proyectos (listado y fichas)
- Eventos (búsqueda y filtros)
- Donaciones (formulario seguro)
- Notificaciones (logros y campañas)

## Stack
- HTML5, CSS3, JavaScript
- (Opcional) Backend Node.js / PHP
- Control de versiones: GitHub (PRs, Issues, Branches)

## Convenciones Git
- Ramas por feature: `feature/<nombre>`
- Commits: `feat|fix|docs|refactor|test(scope): mensaje`
